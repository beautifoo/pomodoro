About 5 minutes before a pomodoro ends, the agent gets a heads-up after a tool result, so it brings the current step to a stopping point and doesn't start anything big. It comes once per pomodoro, only while the agent is working, never while quiet or on a break. It's a message the terminal doesn't show, and it adds no request to the model.
